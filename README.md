# 到期管家

面向 Scripting 的到期提醒工具，支持周期事项、费用概览，以及服务器邮件代发。

## 3.1.0

- 修复普通启动或临时空数据可能清空服务器代发计划的问题
- 新增“按完成日期滚动”的周期计算方式
- 新增费用概览、年度支出和未来 30 天支出统计
- 保留长期滚动邮件代发、提前提醒与到期日再次提醒
- 同步密钥保存在系统钥匙串，不写入源码仓库

## 安装

下载仓库根目录的 `due-manager.scripting`，在 Scripting 中打开安装。

## 安全说明

仓库不包含 SMTP 授权码、服务器同步密钥或 SSH 私钥。服务器地址和发件配置仍需在应用或服务器端自行设置。
